A photograph replaces the symbol when it sits beside the word file.
Use the word id as the file name: mom.jpg, mom.png, mom.gif, mom.webp, or mom.avif.
The native app also accepts bmp, tif, and tiff through ImageMagick.
SVG and PNG do not need ImageMagick. Other photographs do, on the native app.
The web page shows the file in the picture itself.
